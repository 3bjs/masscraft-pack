# MassCraft Ultra

Realistic graphics for the MassCraft Minecraft server.

This is **optional**. MassCraft works fine without it. You need Minecraft Java Edition on a PC with a good graphics card, so it won't run on Bedrock, phones or consoles.

## Install

1. Install [Prism Launcher](https://prismlauncher.org/) (free) and sign in with your Microsoft account.
2. Download **[MassCraft-Ultra.mrpack](https://github.com/3bjs/masscraft-pack/raw/main/MassCraft-Ultra.mrpack)**.
3. In Prism, click **Add Instance**, then **Import**, and choose the file you downloaded.
4. Right-click the new instance, then go to **Edit**, **Settings**, **Java**. Turn on **Memory** and set the maximum to **4096 MiB**.
5. Press **Launch**, open **Multiplayer**, and join **MassCraft**. It's already in your server list.

For voice chat, type `/voice` in-game and talk from a browser, the same as everyone else.

## In-game keys

| Key | What it does |
|---|---|
| **K** | Turn the shaders on or off. Press this if the game runs slowly |
| **I** | Shader settings |
| **C** | Hold to zoom |

## What's inside

- [Complementary Shaders Unbound](https://modrinth.com/shader/complementary-unbound) by EminGT, the realistic look
- [Iris](https://modrinth.com/mod/iris), which runs the shaders
- [Sodium](https://modrinth.com/mod/sodium), which makes the game run faster
- [Continuity](https://modrinth.com/mod/continuity), which gives glass and bookshelves smooth connected textures
- [Zoomify](https://modrinth.com/mod/zoomify), for zooming in (uses YetAnotherConfigLib and Fabric Language Kotlin)
- [LambDynamicLights](https://modrinth.com/mod/lambdynamiclights), which makes torches glow in your hand
- [Fabric](https://fabricmc.net/), which loads the mods

The pack file only lists these mods. Your launcher downloads each one from Modrinth and checks that it's the right file.

OptiFine isn't included because it doesn't work with Sodium and Iris. These mods cover its main features.

## The server pack

The `schoolcraft-*.zip` files are MassCraft's server resource pack. You don't need to download them, because the server sends one when you join.
